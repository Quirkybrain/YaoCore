## 3. 状态机与关键不变量

1. **控制**：`IDLE → PENDING → COMMITTED | REVERT`。PENDING 不写 confirmed；超时/失败/MISMATCH 进入 REVERT，320ms 自动回 IDLE（页面也可 `settleRevert`）；late result 由 per-device token 丢弃；无自动重试。
2. **连续控制**：同一设备最多 1 条在途；55ms 窗口只保留 latest；TouchUp 取消 timer 并保证最终值；`cancelContinuous` 丢弃 pending、不发包、回弹到 confirmed。
3. **门锁**：`PENDING → GATEWAY_CONFIRMED`（ACK accepted + reported open==false）；GATEWAY_MERGED→SECURED；CONTACT_SENSOR→WAITING_CONTACT；10s 在线→UNCONFIRMED、离线→UNKNOWN；NONE→UNVERIFIED；SECURED 后门磁打开→OPEN + alert。
4. **家庭/加入**：IDLE→JOIN_REQUEST_READY→WAITING_FOR_INVITATION→CODE_REQUIRED/VALIDATING→APPLYING→COMPLETED；`COMPLETED` 后仍需本地档案；密码不进入 state。
5. **配网**：权限→扫描→握手→Wi-Fi→下发→绑定；任何 cancel/fail/back(step≥2) 调 `ble.cancel()`、销毁本 session 草稿、清空 PoP/Wi-Fi；`BOUND` 仅在 result + commitBinding + addGateway 全成功后。
6. **场景**：预检由 C-11 完成；VM 只透传进度；PARTIAL_FAILED 显式保留 `noRollbackNotice`；SKIPPED 不显示成功；取消只停止后续步骤。
