### 2.1 `SCENE_RUN_IN_PROGRESS` 双键说明

- DES-B §6.2 要求 `errors.scene.run_in_progress`；`AppError` 既有 `ErrorCatalog` 规则会把 `SCENE_*` 映射为
  `errors.app.scene_run_in_progress`（T-09 已实现，T-10 不改 `AppError.ets`，写范围外）。
- 因此 rawfile 同时提供：
  - `errors.scene.run_in_progress`（契约键，`I18nKeys.appError`/`ErrorI18nMapper.appKey` 使用）；
  - `errors.app.scene_run_in_progress`（兼容直接读取 `AppError.i18nKey` 的既有代码）。
- 两键同文案、同存储；`ErrorI18nMapper` 是 UI 的唯一入口，建议 T-17/T-18 不直接使用 `AppError.i18nKey`。
